# Moonfall Run (문폴 런) 🌙

달빛의 소녀 루나(Luna)와 함께하는 3D 판타지 무한 러닝 액션 게임입니다.  
HTML5, CSS3, TypeScript, Three.js 및 Capacitor를 기반으로 제작되었으며, 브라우저 및 Android 독립 실행 앱을 완벽하게 지원합니다.

---

## 🎮 주요 기능

1. **3D 캐릭터 & 절차적 애니메이션**
   - Three.js 기본 지오메트리 계층 구조로 은빛 머리, 남색 망토, 달 펜던트를 지닌 루나 모델링
   - 7종 절차적 애니메이션: 달리기(Run), 점프(Jump), 낙하(Fall), 착지(Land), 슬라이딩(Slide), 충돌(Hit), 게임오버(Die)
   - 모바일 스와이프 & PC 키보드 (`A`/`D`: 레인 이동, `W`: 점프, `S`: 슬라이딩, `ESC`: 일시정지)
   - 1개 입력 버퍼링 지원으로 빠른 연속 조작 보장 및 레인 이탈 방지

2. **5종 장애물 & 검증된 안전 패턴 시스템**
   - **끊어진 다리 (Broken Bridge)**: 점프로만 회피 가능, 낙하 시 즉사
   - **무너진 석조 기둥 (Ruined Pillar)**: 최대 2개 레인 차단, 레인 이동으로 회피
   - **낮은 석조 아치 (Low Arch)**: 슬라이딩으로만 안전 통과 (기립/점프 시 충돌)
   - **무너지는 발판 (Crumbling Platform)**: 접근 시 흔들림 경고 후 붕괴
   - **이동 장애물 (Moving Obstacle)**: 좌우 규칙적 왕복 이동
   - 거리 비례 난이도 점진 개방, 속도에 따른 Z 간격 보정, 동일 패턴 연속 배제, 3레인 동시 차단 방지

3. **달의 파편 & 성장 업그레이드**
   - 코인 자석(Magnet): 주변 달의 파편을 플레이어에게 강하게 흡인 (Lv 1~5)
   - 달빛 보호막(Shield): 장애물 1회 충돌 방어 및 쿨다운 재생성 (Lv 1~5)
   - 시작 보너스(Head Start): 시작 시 즉시 거리 부스트 및 보너스 코인 지급 (Lv 1~5)

4. **Web Audio API 절차적 사운드**
   - 외부 파일 없이 100% 자립 재생되는 신디사이징 오디오 (BGM 아르페지오, 점프, 슬라이딩, 코인 차임, 피격, 실드 파괴음)

5. **모바일 최적화 & Capacitor Android 패키징**
   - 설정에서 그래픽 품질 실시간 조절 (Low / Medium / High)
   - Android 백그라운드 전환 시 자동 일시정지
   - Android 하드웨어 뒤로가기 버튼 처리
   - 햅틱 진동 피드백 (`@capacitor/haptics`)

## 🚀 실행 및 빌드 방법

### 1. 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000` 접속

### 2. 자동화 단위 테스트 실행
```bash
npm run test
```

### 3. 프로덕션 웹 빌드
```bash
npm run build
```

### 4. Android 프로젝트 동기화 및 실행
```bash
npx cap sync
npx cap open android
```
